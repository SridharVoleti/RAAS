**# Model Routing Policy**



**## Default Local Model**

**Use Ollama with:**

**- qwen2.5-coder:7b**



**for:**

**- implementation**

**- CRUD APIs**

**- boilerplate**

**- tests**

**- refactoring**

**- documentation**



**## Claude Usage**

**Use Claude only for:**

**- architecture**

**- orchestration**

**- debugging**

**- security review**

**- scalability analysis**

**- complex reasoning**



**## Escalation Conditions**

**Escalate from qwen to Claude when:**

**- implementation repeatedly fails**

**- architecture is unclear**

**- debugging becomes multi-module**

**- security-sensitive logic is involved**
